# Career Hub 工单小游戏 — 需求与实现概要（给 Codex 复刻用）

## 一、目标与约束
- 做一个可爱漫画风 / 软萌风格的**在线小游戏网页**（横版优先，适配 Windows / Android / iPad 浏览器）。
- **不需要上架 App Store**；纯前端即可。
- 品牌语境：Workday **Career Hub**；主题色偏**蓝色**（不要太粉嫩）。
- 主 Slogan：`Dare to Develop`
- 副标题：`Act on your career development plan`
- 右上角使用官方/提供的 **Workday logo 图片**（不要用临时 SVG 字标）。
- 左上角**不要**「今日 Slogan」标签。

## 二、玩法流程
1. **打开页面直接进入答题页**（不要封面/开始页）。
2. 每次随机出现 1 个工单（**不显示工单编号**），展示：
   - 工单标题（如「推荐不够准」）
   - 正面问题文案
3. 下方/侧边给出 **5 个 Solution 选项**（把 5 张工单的正确解法打乱后作为选项）。
4. **选对**：进入成功页，显示：
   - 醒目「通关成功」
   - `Dare to Develop`
   - 该工单的「匹配后提示」
   - 按钮「再来一题」
5. **选错**：进入失败页，显示：
   - 醒目「回答错误」
   - 「再试一次」+ 安慰文案
   - 按钮「重来」（重新随机一题）
6. 成功/失败页要**足够大、一眼能分清对错**（绿色成功 / 红色失败，大字号、大吉祥物，不要挤在屏幕中间一小块）。

## 三、五张工单内容（必须保留语义）

### 工单 01｜推荐不够准
- 正面：我的职业资料还不完整，想让系统推荐更贴近我，应该先做什么？
- Solution：Career Hub → 更新 Skills 和 Skill Interests → 重新查看个性化推荐
- 匹配后提示：资料越完整、更新越及时，系统越能理解你的方向。

### 工单 02｜下一步怎么走
- 正面：我想了解当前岗位之后有哪些发展方向，应该从哪里开始？
- Solution：Career Hub → Plan → Launch Career Path Builder
- 匹配后提示：Career Path 用于探索可能性，不代表岗位承诺或自动获得机会。

### 工单 03｜想试试新领域
- 正面：我想通过短期项目体验新领域，应该从哪里开始？
- Solution：Career Hub → Browse Gigs → Express Interest，并给 Gig Host 留言
- 匹配后提示：这里介绍的是操作入口；具体 GIG 机会请前往 Boss 直聘 Booth。

### 工单 04｜直接查看匹配岗位
- 正面：我的职业资料已经准备好，想直接查看当前匹配岗位，应该从哪里进入？
- Solution：Career Hub → Featured Next Move → 打开岗位信息并进入 Workday 申请流程
- 匹配后提示：具体岗位与 Hiring Manager 请前往 Boss 直聘 Booth。

### 工单 05｜有合适岗位，提醒我
- 正面：我想在出现符合偏好的岗位时收到通知，应该如何设置？
- Solution：Career Hub → Manage Job Alerts → 设置岗位偏好与提醒条件
- 匹配后提示：定期检查并更新偏好，能让岗位提醒更贴近你的需求。

> 选项文案可略压缩以适配单行/两行，但路径语义必须正确，判定仍按完整正确解匹配。

## 四、布局要求（横版）
- 整体铺满，避免中间窄条、两侧大留白。
- 推荐结构：
  - **顶栏**：左侧 `Dare to Develop` + 副标题；右侧 Workday logo 图。
  - **主区左右分栏**：
    - **左侧**：5 个 Solution（A–E），字号要够大；尽量保持可读，空间不够可两行，避免右侧大片空白或被 `...` 严重截断。
    - **右侧**：工单标题 → **问题气泡在上** → **Career Hub 小熊在下**。
- 不要：层层黑粗边框套框；用浅色块、留白、轻阴影分区即可。
- 中英文字重尽量统一（同一套圆润可爱字体，如 ZCOOL KuaiLe + 英文配套）。

## 五、吉祥物（核心视觉）
- 需要一个 **Career Hub 代言小熊**（风格参考抖音/短视频很火的「一二布布」软萌小熊：圆耳、大眼睛、腮红、连帽卫衣）。
- 衣服上印 **Career Hub**。
- 图片需**透明背景**，不要棋盘格、不要抠掉头/耳朵（绿幕抠图比按浅色洪水填充更安全）。
- **答题页**：小熊要有「活」的动作——类似 GIF 的**挥手逐帧动画** + 轻微身体晃动；速度不要太快（约 0.4–0.5 秒/帧较合适）。
- **成功页**：开心举手小熊（完整无边）。
- **失败页**：难过表情小熊（完整无边）。
- 结果页小熊要明显放大。

## 六、视觉与交互细节
- 主题：蓝白为主，点缀 Workday 金/橙可用在 logo。
- 选项带 A–E 彩色圆标，可点击；选对/选错有短暂高亮反馈。
- 成功页展示对应「匹配后提示」；失败页不剧透正确答案，只引导重来。
- 移动端/竖屏可降级为上下堆叠，但仍可用。

## 七、技术建议
- 纯静态：`index.html` + `styles.css` + `game.js` + `assets/` 图片。
- 无需后端；双击 / 本地服务器打开即可。
- 随机抽题 + 打乱 5 个 solution；比较字符串判定对错。
- 图片缓存更新可用 `?v=` 查询参数。
